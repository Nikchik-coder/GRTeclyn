# BinaryWormholeMerger -- Phase 2 single-throat regression (research/merger/Plan.md).
#
# The new binary example run in its SINGLE-THROAT mode (throat B removed
# entirely), reproducing the unperturbed configuration of
# research/wormholedynamics/article.md.  The gate is that the published
# physics comes back out: the throat sits in saddle-point equilibrium at
# R_areal = 0.50 for t ~< 1.5, then truncation noise tips it into the
# RAREFACTIVE branch and it expands exponentially at lambda ~ 9.012.
# Any disagreement is a bug in this example, not new physics.
#
# Only the UNPERTURBED branch is reproduced here.  The article's perturbed
# collapse also needs a seeded Gaussian scalar perturbation (A_phi = +0.02,
# sigma_phi = 0.5), and those knobs were deliberately removed from this
# example -- a merger must not start with pre-destabilised throats, since the
# other throat is the perturbation.  Reproducing that branch needs the knobs
# back, gated to single-throat mode; see Plan.md Phase 2.
#
# Launch through the campaign launcher, never directly:
#   WHM_PARAMS=params_phase2_single.txt bash grteclyn-wrapper/scripts/campaigns/wormhole_merger/run_single.sh
# The three path keys below are placeholders the launcher rewrites (each must
# appear exactly once).

# The thing being measured is where equilibrium ends and the rarefactive
# runaway begins, and at lambda ~ 9 that transition is over in well under 1 M,
