# BinaryWormholeMerger -- Stage 1: does ONE regular throat hold still?
# (research/merger/FIx.md, implementation plan Stage 1.)
#
# Stage 0 proved the throat survives being put on a grid.  This asks the next
# question and it is a much sharper one, because the single massive drainhole
# is not merely "good" initial data -- it is an EXACT FIXED POINT of the whole
# evolved system:
#
#   gamma-tilde_ij = delta_ij  (the data is conformally flat)  ->  Gamma^i = 0
#   K = 0, A_ij = 0, Theta = 0
#   beta^i = 0, B^i = 0        (Gamma-driver starts and stays at zero)
#   alpha  = e^{u}             (static; 1+log has d_t alpha = -2 alpha K = 0)
#
# Every evolved variable is at a stationary point of its own RHS at t = 0.  So
# with wormhole_initial_lapse_type = 5 there is no transient to ride out and no
# gauge relaxation to disentangle: ANY drift is either the discretisation or
# the physical Ellis-Bronnikov unstable mode, and nothing else.  That is what
# makes this the run that can actually answer the question.
#
# The one thing that is NOT a fixed point is the origin-isolating collar.
# alpha = e^{u} * collar is not the static lapse, so lapse type 6 injects a
# real perturbation near rbar = 0 by construction.  It exists because chi still
# vanishes like rbar^4 at the compactified far infinity and CCZ4 divides by
# chi.  Which of the two survives is FIx.md Stage 1.3, and it is run as a
# straight A/B on this one file:
#
#   WHM_NAME=stage1 WHM_PARAMS=params_stage1_hold.txt WHM_MAX_LEVEL=2 \
#     WHM_KEEP_PLOTFILES=1 \
#     WHM_CONSUME_ARGS="--areal-radius --areal-min-radius 0.8" \
#     WHM_LAPSE_TYPE=5 WHM_GPU=0 \
#     bash grteclyn-wrapper/scripts/campaigns/wormhole_merger/run_single.sh
#   ... and the same with WHM_LAPSE_TYPE=6 WHM_GPU=1.
#
# Configuration: one throat, a = 2, m = 1, so M_ADM = 1 and stop_time = 40 is
# 40 M.  Closed-form predictions (drainhole_throat_check.py):
#   minimal surface   rbar  = 1.6180      areal radius R_min = 3.8895
#   chi at the throat = 0.1731            alpha at the throat = 0.4159
# The run passes if R_min holds 3.890 for 40 M with drift attributable to the
# known EB mode (one growing mode, timescale ~ throat/c ~ 4) rather than to the
# grid, and the constraint norms stay flat.
#
# The three path keys below are placeholders the launcher rewrites.
