# BinaryWormholeMerger -- Stage 2.0 shakedown: does a MOVING throat survive?
# (research/merger/Plan.md, Stage 2.0.)
#
# Stage 1 proved the throat can sit still for 40 M.  A merger needs more than
# that: during infall and any spiralling each throat has to cross the grid,
# and every piece of Stage 1's evidence was collected with the throat pinned
# to the grid centre by construction.  This run is the boosted-puncture test
# of black-hole codes, transplanted: ONE drainhole (a = 2, m = 1, the Stage 1
# object), given a Bowen-York momentum P = 0.2 along z, followed by moving
# refinement boxes.  Two questions, in order of importance:
#
#   1. infrastructure - does the tracker hold the throat and do the moving
#      boxes keep it resolved while it crosses cells, refinement boundaries
#      and box edges?  (throat_track.dat: n cells > 0 throughout, position
#      advancing at ~ P/M = 0.2.)
#   2. physics - does motion seed the known growing mode harder than rest?
#      The Stage 1 baseline at max_level = 3 reached t = 40 clean with L2 Mom
#      still growing (e-fold ~ 4.4).  This data is NOT an exact solution: the
#      Bowen-York term violates the Hamiltonian constraint at t = 0 (the
#      momentum constraint stays exact - K = 0, Pi = 0), so the seed is
#      larger and the wall should arrive EARLIER than 40 by about
#      4 x ln(seed ratio).  Where it lands is the number Stage 3 needs
#      before it can budget the infall.
#
# What P = 0.2 represents: the Newtonian relative speed of an equal-mass pair
# at separation d = 16 is sqrt(M_tot/d) ~ 0.35, i.e. ~ 0.18 per throat.  So
# 0.2 is a genuine late-inspiral speed, not a gentle nudge.  Drift over 40 M
# is ~ 8 units: the finest moving box (half-width 2) ends near z = 10, well
# inside the sponge at 24.
#
# This is a VALIDATION arm, not the merger.  The merger itself stays
# gravity-driven (two throats released from rest, Plan.md Stage 3); aimed
# momenta are never used to fake an attraction there.
#
