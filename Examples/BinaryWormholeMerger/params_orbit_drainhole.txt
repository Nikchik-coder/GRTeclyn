# BinaryWormholeMerger -- Stage 2.5: TWO drainhole throats on a bound orbit.
# (research/merger/Plan.md; follows the Stage 2.0 boosted single throat.)
#
# Everything Stage 2.0 validated is kept byte-for-byte: drainhole data
# (id_type = 1) with the mass in the lapse, lapse type 5, sigma = 0.1,
# moving nested boxes (tagging_type = 2) on the tracked throats, sponge
# 24 -> 32.  What changes is the physics: two equal throats (a = 2, m = 1,
# M_ADM = 1 each) at d = 12 along x, given tangential Bowen-York momenta
# in +/-y.  The momenta only SET THE INITIAL ORBIT -- the inspiral and
# merger are gravity-driven, per the standing rule.
#
#   P = 0.12 per throat, vs the Newtonian circular value 0.204 at d = 12
#   (v^2 = M/2d).  Sub-circular on purpose: a bound, plunging spiral that
#   merges within the window the Stage 2.0 arm proved clean.  That arm
#   showed a P = 0.2 boost collapses a single throat at t = 36.7 through
#   its own constraint violation, so the orbital momenta stay well below
#   0.2 and the merger should arrive first (Newtonian free-fall from rest
#   at d = 12 is ~16; with this angular momentum expect t ~ 20-30).
#
# Checkpoints every 2000 coarse steps = every 20 time units (dt_coarse =
# dt_multiplier * L/N1 = 0.01): t = 20, 40.  These are the restart-test
# fixtures for the WHM_RESTART launcher hook.
#

# through the grid centre shows the whole motion.
