# Metric search verifier ladder

Nobody picks a metric. A proposal poses a problem — matter, symmetry, topology, boundary conditions, a seed — and a coupled Einstein-plus-matter solve finds whatever metric answers it. New families arrive as new solution branches, survivors reach GRTeclyn as tables, and any new C++ matter waits at a gate. The brick catalog below is the entire input language. ## How the updated loop works

- Proposers**A proposal poses a problem, not a metric**

  Each candidate is a card snapped together from the brick catalog at the top of this page: matter bricks, a symmetry class, a topology with boundary conditions, one dial to crank, and a starting guess. The metric itself is the solver's output. Nothing here writes C++.
- Tier 0 · ms to s**Reachability and sanity**

  Sympy derives the field equations from the stated action, and a representability check asks whether that matter can produce the stress pattern the problem needs at all — the test the old projection loop never ran. Known limits must come back as regressions.
- Tier 1 · seconds**Solve metric and matter together**

  Newton plus continuation on the coupled Einstein-and-matter system, with the metric functions as unknowns — the spinning-wormhole solver generalized. Where the Jacobian goes singular, a new branch sprouts, and following it is how families nobody wrote down are found. Solutions count only on identities the solver never imposed.
- Tier 2 · seconds**Measure it**

  How much earlier light arrives than in flat space, how much negative energy that costs, whether horizons or time loops appear, and whether it is a known solution in disguise.
- Tier 3 · seconds to minutes**Nudge it**

  A small-perturbation test, the linear-mode check generalized to each family. If anything grows, the candidate stops here and its growth rate is recorded.
- Tier 4 · GPU-hours**Hand it over as a table**

  The solution is saved as a table and loaded straight into GRTeclyn, the way the spinning-wormhole backgrounds are. No GRTresna step and no change to the C++.
- C++ gate · rare**New matter waits**

  If a winner needs matter GRTeclyn does not have, the agent drafts the C++ class. It goes through the contract test, the build, preflight and your go before any GPU run.
- Feedback**Every failure explains itself**

  The agent gets the reason back: a sympy mismatch, a failed identity, a growing mode. Lineages that learn from it pass more often.
- Archive**Trade-off curve plus loophole map**

  Results form a trade-off between shortcut size, negative-energy price and stability, filed by which no-go assumption each design breaks. Empty cells are untried loopholes.

Two one-off code jobs make this work: a general table loader so any new family reaches 3D without touching C++, and potentials whose shape is set at runtime instead of compiled. First FTL-grade problems to pose: a smooth intra-universe ring wormhole, and a static Krasnikov-style corridor.
