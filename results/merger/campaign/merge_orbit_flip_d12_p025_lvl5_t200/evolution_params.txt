#   arm C  ctrl_flip_d12  phi_sign_B = -1, from rest  accel -0.0185 TOGETHER
#
# Arm C's pull/push ratio held at 1.50 across five separate times against a
# prediction of exactly 6/4 = 1.50, which fixes both the magnitude (5x
# gravity) and the sign rule (same orientation repels, opposite attracts).
#

# field through its slope squared, so geometry, ADM mass, supporting energy
# density and the growth mode are all invariant under phi -> -phi: an
# isolated anti-wormhole is the Stage 1/2.0 throat, and inherits its
# 40 M shakedown record wholesale.  Orientation only acts BETWEEN bodies.
#
#   net radial pull  = (1 + 5) x gravity = 6x,  vs 4x outward like-charge.

# circular momentum for a 6x central force (sqrt(6) x 0.204 = 0.50), so

# collapsed a single Stage 2.0 throat at t = 36.7.
#

# throat: the merged object has zero net scalar charge, and a throat cannot
# stay open without its field.  The predicted endpoint is collapse to an
# ordinary black hole plus radiated scalar -- horizon-formation time and
# radiated fraction are the two numbers this run exists to produce.
