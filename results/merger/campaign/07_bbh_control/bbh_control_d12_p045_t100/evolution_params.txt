# BBH vacuum control at the FLY-BY's momentum: d = 12, p = 0.45, no scalar.
#
# WHY.  The paper says the fly-by radiates "29x an equal-parameter vacuum
# binary", and the vacuum binary it means is bbh_control_d12_p012_t150 --
# which carries p = 0.12, the SPIRAL's momentum, not the fly-by's.  A vacuum
# pass at p = 0.45 radiates far less than a vacuum merger, so 29x understates
# the excess and the abstract underclaims through a mislabelled control.  This
# arm is the missing denominator.
#
# ONE KNOB.  Byte-identical to params_bbh_control_d12_p012_t150.txt except:
#   bh{1,2}.momentum  +/-0.12 -> +/-0.45 y   (the question)
#   stop_time         150 -> 100            (nothing merges; see below)
#   amr.check_int     100 -> -1             (no checkpoints, on the user's word)
# The bare puncture masses are NOT retuned.  At p = 0.12 the P^2 contribution
# to each puncture's ADM mass is under 1 % and the comment in the p012 template
# says so; at p = 0.45 it is ~10 % (P^2/2m = 0.2025/1.923), so this pair is
# heavier than the p012 control by about that much.  That is deliberate: the
# wormhole fly-by dialled its momentum the same way, with the mass parameter
# held at m = 1, and every energy in the paper is quoted in units of its own
# record's ADM mass.  Read the actual masses off punctures_output/ before
# quoting a ratio.
#
# WHAT TO EXPECT.  In vacuum the circular momentum at d = 12 is the Newtonian
# 0.204 and the parabolic value is 0.289, so p = 0.45 is strongly hyperbolic:
# unlike the wormhole fly-by -- which fell 12 -> 4.82 first, because its
# scalar attraction is 6x gravity -- this pair starts AT periapsis and only
# separates.  Relative v_inf ~ 0.69c, so the punctures reach the sponge
# (r = 24) at t ~ 50 and the box edge at t ~ 75.  There is no close encounter
# and no merger; the radiated energy will be small and partly initial-data
# junk, which makes it an UPPER bound on a vacuum pass and therefore a LOWER
# bound on the fly-by's excess.  That is the honest direction, and it is the
# whole point of running it.  stop_time 100 is past the useful window twice
# over; gate per sphere as everything else in this campaign is gated.
#
# CCZ4 constants match the wormhole campaign (kappa1 = 3, kappa2 = 0,
# covariantZ4 off, derivative order 4).  dt_multiplier and sigma are NOT the
# wormhole values: 0.02/0.1 there are phantom-stiffness choices; vacuum runs
# the standard 0.25/0.5.  Same initial data, standard vacuum numerics.
