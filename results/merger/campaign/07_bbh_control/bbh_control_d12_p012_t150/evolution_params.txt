# BBH vacuum control for the wormhole merger campaign (GPU_PLAN section 8.1).
#
# Same IVP as the headline p = 0.12 drainhole arm: two M_ADM ~ 1 objects,
# d = 12 apart along x, transverse Bowen-York momenta +/-0.12 y, same L = 64
# box.  Bare puncture mass 0.9615 gives per-hole ADM ~ 1.00 at this
# separation (Brill-Lindquist: M_ADM = m_bare(1 + m_other/(2d)) = 0.9615 *
# 1.0401; the P^2 contribution adds under 1 %).
#
# CCZ4 constants match the wormhole campaign (kappa1 = 3, kappa2 = 0,
# covariantZ4 off, derivative order 4).  dt_multiplier and sigma are NOT the
# wormhole values: 0.02/0.1 there are phantom-stiffness choices; vacuum runs
# the standard 0.25/0.5.  Same initial data, standard vacuum numerics.

# ---- initial data: the matched IVP ----
bh1.mass = 0.9615

# ---- grid: the wormhole box ----
